# Inventory Management System 📦

A robust desktop application developed using C# and Windows Forms. This system is designed to streamline inventory operations, manage products, and keep track of customers and employees efficiently.

## 🚀 Features
* **Product Management:** Add, update, and track product details and stock levels.
* **Customer Records:** Maintain customer information for seamless transactions.
* **Employee Tracking:** Manage worker details within the system.
* **User-Friendly Interface:** Built with Windows Forms for intuitive navigation and ease of use.

## 🛠️ Technologies Used
* **Language:** C#
* **Framework:** .NET Framework (Windows Forms)
* **Architecture:** Object-Oriented Programming (OOP)
